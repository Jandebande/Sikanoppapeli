# Sika-noppapeli

Selaimessa pelattava Sika-peli yhden ja kahden nopan versioina.

## Käynnistäminen
Avaa `index.html` selaimessa. Erillistä palvelinta tai asennuksia ei tarvita.

## Tiedostot
- `index.html` – käyttöliittymä
- `style.css` – ulkoasu
- `script.js` – pelilogiikka
- `SUUNNITELMA.md` – projektisuunnitelma
- `AJANKAYTTO.md` – ajankäytön seuranta
- `LOPPURAPORTTI.md` – loppuraportin pohja
- `loppuraportti.pptx` – PowerPoint-esityksen pohja

## Julkaisu GitHub Pagesissa
1. Luo GitHubissa uusi repository.
2. Lisää kaikki tämän kansion tiedostot repositoryyn.
3. Avaa repositoryn Settings → Pages.
4. Valitse Build and deployment -kohdasta Deploy from a branch.
5. Valitse `main` ja kansio `/ (root)`, tallenna.
6. Avaa Pages-asetuksissa näkyvä julkaistu URL.

Täytä ajankäytön seuranta ja loppuraportin testausosio omien havaintojesi perusteella.
